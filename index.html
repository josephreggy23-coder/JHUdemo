Quick guide

Review a BodyMaps case

  1. Open a case. Select NIfTI files or a DICOM folder. Files never leave this device.
  2. Inspect anatomy. Scroll slices, right-drag to window, and use the linked crosshair.
  3. Check segmentations. Toggle, solo, search, flag and compare quantitative statistics.
  4. Correct and report. Paint an edit layer, export it as NIfTI, and save a structured QC report.
